# 小程序端（用户小程序）风格基线

> 触发词：目标路径属于 `mini-program/main`（含其平台变体目录）  
> 适用场景：列表、储物、下单、信箱、地址簿等用户小程序页面的设计稿开发  
> 最后更新：2026-08-27

## 1. 定位

本文件为示例项目用户小程序（含多平台变体）沉淀可执行视觉基线，供后续设计稿开发、复刻改造、AI 辅助页面实现共同遵循。

- 各平台小程序变体共用本基线，不单独建文件。
-  shipping 小程序（`mini-program/shipping`）后续合并入用户小程序，其下单 Tab 下的卡片也纳入本基线。
- 不适用于门店小程序、站点管理、移动作业端 App、驻站作业场景、Web 后台。

## 3. 视觉基线

### 3.1 页面壳

- 默认使用 iPhone 设计稿壳：`width: 393px`、`height: 852px`、`border-radius: 50px`。
- 页面外桌面背景：`#1a1a1a` 或深灰色系，用于突出手机壳。
- 手机壳阴影：`0 0 0 12px #333` + 柔和外阴影（`0 0 50px rgba(0,0,0,0.5)`）。
- 手机壳内 `overflow: hidden`，页面内容垂直布局（`flex-direction: column`）。
- 底部 Home Indicator：宽约 `130px`，高 `5px`，底部 `8px`，黑色。
- 小程序右上角胶囊按钮：宽 `88px`、高 `32px`、圆角 `16px`、边框 `1px solid #e5e7eb`。

### 3.2 顶部与状态栏

- 状态栏高度：`54px`（含信号、时间、电量）；字体 `15px`、`600`。
- 导航栏高度：`44px`；标题 `17-18px`、`600-700`；左侧返回按钮约 `34px`。
- 普通业务页：白底导航，标题居中。
- 需要强调氛围时（如订单列表）：蓝色渐变头部 `linear-gradient(180deg, #4B8BF5 0%, #2563EB 100%)`，标题白色。
- 首页可使用品牌色背景或渐变，但不强制所有页面蓝色头部。

### 3.3 背景、卡片与层级

- 页面内背景：`#F5F7FA` 或 `#f6f7f8` 或 `#f6f7f9`。
- 卡片白底（`#FFFFFF`），圆角 `8px`-`12px`；首页功能大卡片可用 `14px`-`16px`。
- 卡片内间距：`12px-16px`。
- 内容区左右边距：`12px-16px`。
- 卡片间距：`8px-12px`。
- 分割线：`#E8E8E8`、`#E7ECF3`、`#edf0f3`。
- 卡片阴影（轻量）：`0 1px 4px rgba(0,0,0,0.05)`。

### 3.4 色彩

- 主色（品牌蓝）：`#1677FF` 或 `#2563EB`。
- 可接受同族蓝：`#2f6fff`、`#4B8BF5`、`#1d4ed8`（渐变或辅助场景）。
- 成功语义（绿色）：`#00B578`、`#14b87a`。
- 危险 / 价格：`#FF4D4F`、`#ff6b00`。
- 警告 / 橙色：`#FF8A1F`、`#FAAD14`。
- 页面背景：`#F5F7FA`。
- 卡片背景：`#FFFFFF`。
- 主文本：`#1A1A1A`、`#111827`、`#172033`。
- 次级文本：`#666666`、`#6B7280`。
- 辅助文本：`#999999`、`#9CA3AF`、`#98a2b3`。

不得为同一语义新增无依据颜色。若 clone-source 与 `standards/design-tokens.json` 不一致，优先用 token 定语义，用 clone-source 收紧视觉。

### 3.5 字体与字号

- 字体族：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", Arial, sans-serif`。
- 页面标题 / 大数字：`18px-21px`，`700-800`。
- 导航标题：`17px`，`600-700`。
- 分组标题 / 卡片标题：`15px-16px`，`600-700`。
- 正文：`14px-15px`。
- 辅助说明：`12px-13px`。
- 标签、状态、角标：`10px-12px`。

### 3.6 按钮与底部操作

- 主按钮：蓝底白字，高度 `44px-48px`。
- 圆角：
  - 底部胶囊主按钮：`22px-24px`。
  - 普通表单按钮：`8px-12px`。
  - 小标签 / 小按钮：`4px-8px`。
- 底部操作栏白底固定，保留安全区（`padding-bottom: calc(10px + env(safe-area-inset-bottom, 20px))`）。
- 底部只保留核心动作，不顺手新增快捷入口或统计条。

### 3.7 表单与输入

- 输入区：浅灰背景（`#f6f7f8`）或白底细边框，圆角 `8px-14px`。
- 地址卡片：白底、左侧图标、右侧箭头，卡片内信息分层（姓名+电话、详细地址）。
- 选择器：点击展开或跳转新页面选择，不使用下拉菜单。
- 开关 / 单选：选中态主蓝，未选中灰色。

### 3.8 列表与卡片组件

- 条目卡片 / 订单卡片：白底，左侧信息区（标题+描述+时间），右侧状态标签或金额。
- 状态标签：小尺寸（`10px-12px`），圆角 `4px`，背景色区分状态（蓝=进行中、绿=完成、灰=历史）。
- Tab 筛选：顶部 Tab 切换（全部/待处理/已完成 等），选中态底部蓝色指示线或蓝色文字。
- 搜索框：圆角 `20px`，浅灰背景，左侧搜索图标。

### 3.9 详情页特有

- 状态头部卡片：蓝色渐变背景（`#2e74f5` → `#1d4ed8`），白色文字，右上角装饰圆。
- 信息分组：白色卡片，内部按行展示（label: value），分割线分隔。
- 时间线 / 进度轨迹：左侧时间线圆点 + 竖线，右侧事件描述。
- 底部操作：固定底部，主按钮 + 可选次要按钮。

### 3.10 需求文档与抽屉

- 小程序默认遵循 `platform-rules.json`：`docPanelMode: auto-open`。
- 需求文档入口使用右侧独立按钮或公共 `dg-doc-btn` / `doc-button.js`，不挤入真实小程序页面内容。
- 需求文档 Tab 与 CSS 规范 Tab 按 `standards/ui-consistency-rules.json` 与 `standards/doc-spec.json` 执行。

## 4. 页面类型执行模板

### 4.1 首页

参考 `小程序首页.html`：

- 顶部场景切换（列表/储物/下单等 Tab 或入口卡片）。
- 功能入口网格或大卡片（蓝色/绿色品牌色背景）。
- 中部内容区按场景动态展示。
- 底部 TabBar 或无（取决于小程序架构）。

### 4.2 列表页

参考 `我的列表.html`、`订单列表.html`：

- 顶部 Tab 筛选（全部/待处理/已完成）。
- 搜索框（可选，圆角浅灰背景）。
- 列表项白色卡片，核心信息先于次级信息。
- 状态标签小尺寸低噪声，同类状态颜色一致。
- 空状态居中展示（图标+文案+引导按钮）。

### 4.3 详情页

参考 `订单详情.html`：

- 蓝色渐变状态头部卡片（状态名称+描述+时间）。
- 信息分组白卡：地址信息、条目信息、费用明细、进度轨迹。
- 底部固定操作栏（主按钮或主+次按钮）。
- 不为所有详情页强制蓝色头部：只有状态驱动的详情页才用。

### 4.4 表单页 / 下单页

参考 `下单页.html`：

- 地址卡片在顶部（发起方、接收方）。
- 条目信息、备注等输入区白底分组。
- 选择类字段用右侧箭头引导跳转选择页。
- 底部固定提交按钮（蓝色胶囊主按钮）。

### 4.5 储物 / 操作页

参考 `储物操作页.html`：

- 操作引导区（图标+文案说明当前步骤）。
- 编号选择或扫码区。
- 底部确认按钮。
- 页面简洁，不堆叠多余信息。

## 5. 禁止项

- 禁止把本基线用于门店小程序、Web 后台、移动作业端 App 或驻站作业场景。
- 禁止脱离仓库规则和 style clone-source 直接生成独立 HTML。
- 禁止把需求说明、开发备注、测试提示、模拟操作写进真实页面正文。
- 禁止为了"更完整"顺手新增筛选器、统计条、快捷入口或新模块区块。
- 禁止机械平均多个页面的 CSS 数值；按目标页面类型选择最接近 clone-source。
- 禁止将特殊交互型页面（如地图类页）作为风格基准——该类型不代表小程序通用风格。

## 6. 验证清单

页面完成前，至少检查：

- 是否仍以 `AGENTS.md` 为主入口，本文件没有替代项目规则。
- 目标是否属于 `mini-program/main`（含平台变体）；否则不得套用。
- 是否声明了 style clone-source 和 change-type。
- 手机壳是否保持 393×852、圆角 50px、底部 Home Indicator。
- 小程序右上角胶囊按钮是否存在。
- 页面背景、卡片、按钮、标签是否落在本基线允许范围。
- 真实页面正文是否没有混入需求说明、开发备注、测试提示。
- 需求文档抽屉是否按小程序默认 auto-open 执行。
