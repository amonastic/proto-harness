## 既有功能视觉遮罩细则

当用户指令包含 `遮罩`、`遮住`、`灰掉`、`标为既有`、`不涉及这个功能`、`老功能标记`、`半透明覆盖` 时：

- 禁止直接写代码
- 必须先做定位范围、影响分析、方案输出、等待确认

默认推荐方案 D：

- 容器追加 CSS class，例如 `.search-item--legacy` 或同等语义。
- 整体 `opacity: 0.5`；hover 时 `opacity: 0.65`。
- 内部所有子元素 `pointer-events: none`。
- `::after` 伪元素叠加 45 度斜纹纹理遮罩层，使用 `repeating-linear-gradient`。
- label 右侧追加「既有」胶囊标签，建议 10px、圆角 99px、`#f3f4f6` 底色。
- 不触碰后续本期新增的控件或筛选项。
- 不同步删除原有控件 DOM，仅做视觉降级。
- 对应抽屉的筛选条件表或字段说明表中，给被遮罩行追加 `既有` 或类似标记。
- 抽屉中不展开被遮罩控件的详细规则，避免信息矛盾。
- 未得到用户明确执行授权时，只能输出定位、影响分析和方案，不得落代码。

若用户明确要求“完全遮住”或等价表达，可按以下细则执行：

- 容器 class：`search-item--legacy`
- 原控件处理：`display: none; pointer-events: none`
- 遮罩元素：`<span class="legacy-mask">复用既有控件</span>`
- 遮罩宽度：按原控件宽度使用 `w-wide` / `w-mid` / `w-xwide`
- label 保持正常显示，不跟随降级
- 查询 / 清空按钮不遮罩

推荐样式基线：

```css
.search-item--legacy { position: relative; }
.search-item--legacy .search-input,
.search-item--legacy .search-select {
    display: none;
    pointer-events: none;
}
.legacy-mask {
    height: 34px;
    display: inline-flex;
    align-items: center;
    justify-content: center;
    font-size: 11px;
    color: #9ca3af;
    background: repeating-linear-gradient(-45deg,
        rgba(156,163,175,0.04) 4px, transparent 8px),
        linear-gradient(180deg, #f9fafb 0%, #f3f4f6 100%);
    border: 1px dashed #d5d7db;
    border-radius: 6px;
    flex-shrink: 0;
}
.legacy-mask.w-wide { width: 168px; }
.legacy-mask.w-mid { width: 148px; }
.legacy-mask.w-xwide { width: 180px; }
```

实现边界：

- 不删除原有 DOM，仅视觉隐藏
- 不改 label 的 class 和样式
- 不把遮罩等同于 disabled 或删除
- 抽屉文档需同步标记“既有 / 本期不涉及”
