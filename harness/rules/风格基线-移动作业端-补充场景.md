# 移动作业端补充场景（驻站作业）风格基线

> 触发词：目标路径属于 `field-app/station-ops`  
> 适用场景：驻站作业 App 的作业单、收件、站点管理、消息等页面设计稿开发  
> 最后更新：2026-08-27

## 1. 定位

本文件为示例项目驻站作业场景（`field-app/station-ops`）沉淀可执行视觉基线，作为 `harness/rules/风格基线-移动作业端.md` 的补充，供设计稿开发、复刻改造、AI 辅助页面实现共同遵循。

- 不适用于 `field-app/main`（移动作业端主场景）、用户小程序、门店小程序、Web 后台。
- 移动作业端主场景有独立基线：`harness/rules/风格基线-移动作业端.md`。
- 两场景虽同属 `field-app/`，但视觉风格、业务场景和 clone-source 各自独立，不得交叉套用。

## 2. Style Clone-source 清单

| 页面 | 路径 | 作为基准时主要吸收 |

## 3. 视觉基线

### 3.1 页面壳

- 默认使用 iPhone 设计稿壳：`width: 393px`、`height: 852px`、`border-radius: 48px-50px`。
- 页面外桌面背景：`#1a1a2e`、`#202020` 或深灰暗色系。
- 手机壳阴影：`0 0 0 12px #333` 或 `0 0 0 12px #242424` + 柔和外阴影。
- 手机壳内 `overflow: hidden`，页面内容垂直布局（`flex-direction: column`）。
- Notch 区域：宽 `120-122px`、高 `35px`、顶部 `10px`、黑底圆角。
- 底部 Home Indicator：宽 `130px`，高 `5px`，底部 `8px`，黑色 `opacity: 0.3`。

### 3.2 顶部与状态栏

- 状态栏高度：`54px`（含信号、时间、电量）；字体 `15px`、`600`。
- 导航栏：白底，标题居中 `17px`、`600`，左侧返回按钮 `32px`。
- 导航栏下方分割线：`1px solid #F0F0F5` 或 `#e8e8e8`。
- 驻站作业场景导航栏不使用蓝色渐变头部（区别于用户小程序）；保持白底简洁。

### 3.3 背景、卡片与层级

- 页面内背景：`#F5F7FA`。
- 卡片白底（`#FFFFFF`），圆角 `14px`（主卡片）；轻阴影 `0 2px 10px rgba(0,0,0,0.04)`。
- 卡片内间距：`16px`。
- 内容区左右间距：`16px`。
- 卡片间距：`12px`。
- 分割线：`#F5F5F5`、`#E8E8E8`、`#F0F0F5`。
- 信息行布局：`label: value` 两端对齐，`padding: 14px 16px`，`border-bottom: 1px solid #F5F5F5`。

### 3.4 色彩

- 主色（蓝）：`#3B82F6`、`#2563EB`。
- 站点管理场景主色：`#0080E9`（偏亮蓝，区别于主场景深蓝）。
- 页面背景：`#F5F7FA`。
- 卡片背景：`#FFFFFF`。
- 主文本：`#1A1A1A`、`#25324b`。
- 次级文本：`#666666`。
- 辅助文本：`#999999`。
- 危险语义：`#FF4D4F`。
- 品牌标识色（圆形 logo）：`#FF6B00`（橙色系，按实际品牌）。

不得为同一语义新增无依据颜色。

### 3.5 字体与字号

- 字体族：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", Arial, sans-serif`。
- 导航标题：`17px`，`600`。
- 卡片主信息（单号等）：`17px`，`700`。
- 正文 / 信息行：`14px-15px`。
- Label（左侧标签）：`14px`，颜色 `#999`。
- 辅助说明：`12px-13px`。
- 状态标签：`11px-12px`。

### 3.6 按钮与底部操作

- 主按钮：蓝底白字或渐变蓝（`linear-gradient(135deg, #3B82F6, #2563EB)`），高度 `44px-48px`。
- 圆角：`10px-14px`（常规按钮），`50%`（圆形图标按钮）。
- 圆形操作按钮（电话、短信等）：`36px` 直径，浅灰背景 `#F5F7FA`，蓝色图标。
- 底部操作栏：白底固定，`padding: 12px 16px`，安全区 `padding-bottom`。
- 底部可放多个按钮（主+次），间距 `10px-12px`。

### 3.7 信息行与详情布局

- 标准信息行：左侧 label（灰色 `#999`），右侧 value（黑色 `#1A1A1A`），两端对齐。
- 行高：`padding: 14px 16px`。
- 分割线：`1px solid #F5F5F5`（最后一行无分割线）。
- 联系人行特殊：可包含电话号码 + 右侧圆形操作按钮（打电话、发短信）。
- 复制图标：紧跟文本右侧，`12px`，灰色。

### 3.8 列表与管理页

- 站点/对象卡片：白底，圆角 `12px-14px`，包含名称、地址、状态标签。
- 搜索框：白底或浅灰底，圆角 `8px-12px`，左侧搜索图标。
- 分类入口：横向排列图标 + 文字，等分宽度。
- 状态标签：小圆角 `4px`，对应颜色背景 + 同色文字。

### 3.9 需求文档与抽屉

- 驻站作业场景默认遵循 `platform-rules.json`：`docPanelMode: auto-open`。
- 需求文档入口使用右侧独立按钮（蓝色渐变圆角按钮）或 `doc-button.js`。
- 右侧可放置控制面板（深色半透明背景，圆角 `22px`，用于场景说明或调试入口）。

## 4. 页面类型执行模板

### 4.1 详情页（作业单详情、已收件）

参考 `作业单详情.html`、`已收件.html`：

- 顶部白底导航（标题 + 返回按钮）。
- 主卡片：作业单核心信息（品牌标识 + 单号 + 联系方式）。
- 信息卡片：标准 label-value 信息行，按业务分组。
- 底部固定操作栏（1-2 个主按钮）。
- 不使用蓝色渐变头部（区别于用户小程序详情）。

### 4.2 列表页 / 管理页（站点管理）

参考 `站点管理.html`：

- 顶部搜索 + 筛选入口。
- 卡片列表（每个站点/对象一张卡片）。
- 卡片内：名称 + 地址 + 状态标签 + 操作入口。
- 分类快捷入口区（图标网格，可选）。

### 4.3 操作结果页

参考 `作业结果-成功.html` 等：

- 居中成功/失败图标 + 结果文案。
- 下方补充信息（编号、时间等）。
- 底部按钮（返回/继续）。

## 5. 禁止项

- 禁止把本基线用于 `field-app/main`、用户小程序、门店小程序或 Web 后台。
- 禁止脱离仓库规则和 style clone-source 直接生成独立 HTML。
- 禁止把需求说明、开发备注、测试提示写进真实页面正文。
- 禁止为驻站作业页面添加蓝色渐变头部（那是用户小程序的风格）。
- 禁止将排除清单中的页面作为风格基准。

## 6. 验证清单

- 是否仍以 `AGENTS.md` 为主入口。
- 目标是否属于 `field-app/station-ops`；否则不得套用。
- 是否声明了 style clone-source 和 change-type。
- 手机壳是否保持 393×852、圆角 48-50px。
- 导航栏是否白底简洁（非蓝色渐变）。
- 信息行是否符合 label-value 两端对齐标准。
- 真实页面正文是否没有混入需求说明或开发备注。
